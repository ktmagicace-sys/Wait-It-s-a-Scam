# 詐欺判定RTA（仮）

スマホ操作を前提にした、DM風の詐欺判定シリアスゲームです。
PCでローカルサーバーを起動し、同じWi-Fi上のスマホからアクセスして操作できます。

## 内容

- DM風UI
- 各会話で3択返信
- 常時「あ、詐欺ね」ボタン
- 詐欺ではない会話も混在
- プレイ中は解説を出さず、最後にまとめてフィードバック
- 結果ログをJSONで保存可能

## 採点ルール

各シナリオは100点満点で、プレイ前に決まった以下の内訳で採点します。

- 回答内容（55点）：詐欺を正しく止める、または通常連絡を誤検知せず完了する
- 見極め（30点）：詐欺の根拠が出た後、危険行動に入る前に判定する
- 回答速度（15点）：1手あたり平均8秒以内で15点、15秒以内で10点、25秒以内で5点、それ以上は0点

回答内容と判定段階の点数はプレイ前に固定されています。

| 結果 | 回答内容 | 見極め | 速度込みの最高点 |
| --- | ---: | ---: | ---: |
| 適切な段階で詐欺を判定 | 55 | 30 | 100 |
| 通常連絡を誤検知せず完了 | 55 | 30 | 100 |
| 根拠が出る前に早押し | 45 | 15 | 75 |
| 危険段階で遅く判定 | 45 | 10 | 70 |
| 誤検知・見逃し・被害 | 0 | 0 | 0 |

判定の早すぎは最大75点、危険段階での遅い判定は最大70点です。誤検知、見逃し、被害は0点とし、速さだけでカバーできない設計にしています。

## シナリオ出典

「SNS投資詐欺・実例6ケース」は、[警察庁 SOS47「SNS型投資詐欺」の実際の事例 Case 01〜06](https://www.npa.go.jp/bureau/safetylife/sos47/case/sns-romance/investment/#example)を基に、学習用の会話と選択肢として再構成しています。原文の個人情報や具体的な振込先は使用していません。

## 起動方法

### 1. zipを解凍

任意の場所に `scam-judge-rta` フォルダを置きます。

### 2. PCでターミナルを開く

解凍したフォルダへ移動します。

```bash
cd scam-judge-rta
```

### 3. 起動スクリプトを実行

```bash
chmod +x serve.sh
./serve.sh
```

ポートを変えたい場合：

```bash
./serve.sh 8080
```

### 4. ターミナルに表示されたURLを開く

`./serve.sh` を実行すると、以下を自動で表示します。

- PCで開くURL
- スマホで開くURL
- ターミナル上のQRコード

スマホのカメラでターミナル上のQRコードを読み取ってアクセスできます。

### 5. スマホでアクセス

PCとスマホを同じWi-Fiにつなぎ、表示されたQRコードを読むか、表示されたURLをスマホのブラウザで開いてください。
